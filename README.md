# docker-project

This is a small Flask app I built to practise Docker, CI/CD and some Linux scripting together in one place. Every time you open the page it saves a visit in a PostgreSQL database and shows how many visits there have been so far. The app and the database each run in their own container with Docker Compose, and the database lives in a named volume, so the count is still there after the containers are stopped and started again. The database password isn't in the code, it's read from a `.env` file that never gets committed. There's also a `/health` route that doesn't touch the database, which GitHub Actions uses on every push: it runs the test, builds the Docker image, starts it and checks that `/health` answers. Finally, `health.sh` is a small bash script that checks disk space, free memory and that both containers are running, and it can be run on a schedule with cron.

To try it, copy `.env.example` to `.env`, set a password, run `docker compose up -d` and open `localhost:5000`.
